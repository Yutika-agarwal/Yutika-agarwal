## How I work

- **Write the product thinking down.** Each project has a problem statement, rejected alternatives, metrics and risks next to the code.
- **Measure, then report the failures.** Evals and guardrail tests run in CI, and the READMEs list what didn't work.
- **Keep personal data local.** Demos use invented data and nothing is sent anywhere by default.
